# Merge Sort em Java

Este projeto apresenta uma implementação do algoritmo **Merge Sort** utilizando a linguagem Java.

O Merge Sort é um algoritmo de ordenação baseado na estratégia **Dividir para Conquistar (Divide and Conquer)**. O funcionamento consiste em dividir o vetor em partes menores de forma recursiva até que cada parte possua apenas um elemento. Em seguida, ocorre o processo de intercalação (*merge*), reorganizando os elementos em ordem crescente.

## Características do Merge Sort

- Algoritmo eficiente para grandes volumes de dados
- Complexidade de tempo: O(n log n)
- Utiliza recursividade
- Ordenação estável
- Baseado em divisão e intercalação de arrays
